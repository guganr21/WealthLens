# WealthLens

Premium dark-themed personal & family financial management website built entirely with HTML, CSS and vanilla JavaScript.

## Features

- 🔐 **100% local** – all data stored in browser LocalStorage (no servers, no accounts)
- 👥 **Multiple profiles** – separate finances per person
- 👪 **Family members** – income, employment, dependency tracking
- 💰 **Income / Expenses** – monthly & annual with frequency normalization
- 🏠 **Assets** – liquid, investments, household, free-text names
- 📈 **Investments** – FD, RD, MF, stocks, ETFs, PPF, EPF, NPS, gold, custom
- 🏦 **Loans** – EMI, outstanding, interest, tenure
- 🛡️ **Insurance** – coverage, premiums, renewal
- 💳 **Banking** – balances & emergency fund coverage in months
- 🌅 **Retirement planner** – scenarios at 55/58/60/62/65 with SIP, gap, readiness
- ❤️ **Financial Health Score** – transparent 0–100 with category breakdown, strengths, weaknesses, recommendations (distinguishes missing vs. zero)
- 📊 **Dashboard charts** – income vs expenses, assets vs liabilities, investment allocation, expense breakdown, net worth (Chart.js)
- 📄 **PDF reports** – professional dark-themed via jsPDF + autotable
- 💾 **Backup** – export/import JSON, reset with confirmation
- 📱 **Responsive** – desktop, tablet, mobile; collapsible sidebar

## Tech stack

HTML5 · CSS3 · Vanilla ES6+ · LocalStorage · Chart.js · jsPDF

No frameworks, no build step, no backend.

## Run locally

1. Download the `WealthLens/` folder.
2. Open `index.html` in any modern browser. That's it.

## Deploy to GitHub Pages

1. Push the `WealthLens/` folder contents to a GitHub repo (or a `/docs` folder).
2. Go to **Settings → Pages** → set source to your branch and folder.
3. Open the published URL.
